# Message-code numbers that were once live and are now retired.
#
# A code number is a stable, searchable identifier. It reaches logs, alert
# rules, support tickets and the published error-code reference, and it outlives
# the release that emitted it. Reusing one for a different condition makes every
# one of those records mean something they did not mean when they were written.
# So a retired number stays retired, and the next code takes the next free
# number rather than the lowest-looking gap.
#
# This file is the list, recovered from the history of Diagnostics.fs, and the
# test beside it refuses any live MessageCode that lands on one. It is
# deliberately NOT regenerated by an approval flag: retirement is one-way, and a
# file a tool rewrites is a file that forgets.
#
# When you REMOVE a code, add its number here in the same commit. The public API
# ratchet will already have failed on the removal, which is where you will be
# reading a diff and can do it.
#
# Each line is a number, then every name the number has ever carried. Two names
# on one line is a number that was reused before this list existed - the thing
# the list is here to stop.
#
